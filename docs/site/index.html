03 / Keep the seams explicit

Valid structure is not permission to execute.

A grammar can establish that a representation is structurally valid. It cannot prove that the model understood the user, that the structure is appropriate for the current context, or that an action is authorized. The host owns context, policy, interpretation, and execution.

What this portal is: a static guide to GrammarAi's two structural models and ownership boundaries. It does not execute grammars or imply a production browser runtime.
